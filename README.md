# Keffaine — Showcase Overlay

Фейковый чит-оверлей для записи видео. Рисует поверх других приложений
интро, вотермарк и полностью рабочее меню. Ничего не читает и не меняет
в других процессах — это только картинка.

## Как собрать APK

### Вариант 1 — Android Studio

1. `File → Open` → папка `KeffaineShowcase`.
2. Дождаться Gradle sync (сам скачает AGP 8.5.2 и Kotlin 1.9.24).
3. `Build → Build Bundle(s) / APK(s) → Build APK(s)`.
4. Готовый файл: `app/build/outputs/apk/debug/app-debug.apk`.

### Вариант 2 — GitHub Actions (без установки ничего)

1. Залить эту папку в новый репозиторий на GitHub.
2. Вкладка **Actions** → **Build APK** → **Run workflow**.
3. Скачать артефакт **Keffaine-debug-apk**.

Сборка длится ~3 минуты. Коммит в `main` тоже запускает сборку.

## Первый запуск

1. Установить APK (нужно разрешить установку из неизвестных источников).
2. Открыть приложение → нажать «Выдать» у красного баннера → разрешить
   «Поверх других приложений».
3. Настроить ник, HWID, FPS/Ping, задержку запуска.
4. «Запустить оверлей» — приложение свернётся, открываешь игру, через
   выбранное время появляется интро и вотермарк.
5. Тап по вотермарку — открывается меню. Вотермарк перетаскивается
   пальцем, позиция запоминается.
6. Остановить — кнопка в приложении или Stop в шторке уведомлений.

## Архитектура

Вся графика — это HTML/CSS/JS в `app/src/main/assets/overlay/`, который
крутится в трёх прозрачных `WebView`-окнах типа `TYPE_APPLICATION_OVERLAY`:

| Окно | Файл | Поведение |
| --- | --- | --- |
| HUD | `hud.html` | на всю площадь экрана, не ловит касания. Интро, прицел, fake FOV, gradient text |
| Вотермарк | `watermark.html` | 400×36 dp, ловит касания, перетаскивается |
| Меню | `menu.html` | 780×510 dp, создаётся по тапу, focusable — работает клавиатура |

Состояние чекбоксов/слайдеров живёт в JS и зеркалится между окнами через
`OverlayService`: включаешь Custom crosshair в меню — он сразу появляется
в HUD. Настройки переживают перезапуск.

Ключевые файлы:

- `assets/overlay/spec.js` — все вкладки, блоки и строки меню одним
  декларативным списком. Добавить функцию = добавить одну строчку.
- `assets/overlay/style.css` — цвета, градиент, блюр, все анимации.
- `assets/overlay/app.js` — рендер контролов, HSV-пикер, ESP-превью.
- `assets/overlay/settings.html` — экран настроек самого приложения.

## Правка под себя

Цвет бренда — `--grad` в `style.css` (сейчас точно из твоего SVG:
`#A9CDFF → #98A3B3 38.5% → #A9CDFF`).

Шрифт — `assets/overlay/fonts/KfMono-*.ttf`. Можно заменить любым другим
моноширинным, имена файлов оставить те же.

Картинка в ESP-превью — `assets/overlay/img/esp_model.png` (PNG без фона).
Скелет привязан к нормализованным точкам `JOINTS` в `app.js` — при замене
картинки подкрути их.

## Отладка без телефона

`Keffaine_Preview.html` рядом с проектом — весь оверлей в одном файле.
Открывается в любом браузере, работает точно так же, как на телефоне.
